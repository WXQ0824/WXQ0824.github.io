## 一、防火墻的产生

1、路由器——万物互联\
      本质：通信\
      产生“安全上网”的需求\
2、防火墙——安全隔离\
      本质：不通\
      防火墙是路由器的升级版，是配置满ACL的路由器（deny any）\
      <span style="color: rgb(224, 62, 45);">**重点：防火墙使用的时候除了路由器的传统使用方法，一定要注意划分安全区域和安全策略规划**</span>\
3、防火墙的作用\
      防火墙会针对流量做分析判断——提供木马库、病毒库、筛选检查、避免合法用户携带非法木马和病毒\
      以下为四个安全区域：\
            i ) 员工上网——从内网到外网——内网始发——trust（信任区域）、区域优先级：85\
            ii ) 服务提供——从外网访问特定内网（服务器）——dmz（服务器区域）、区域优先级：50\
            iii ) 远程办公——从外网访问内网（ssl vpn--OA提流程 / ipsec vpn--微盘服务）——untrust（不信任区域）、区域优先级：5\
            iv ) 防火墙本身——保护防火墙自身安全不受侵害——local（本地区域）、区域优先级：100\
    安全区域中，一个安全区域可以有多个接口，但一个接口只能属于一个安全区域

## 二、防火墙的使用

1、防火墙所有安全策略或者所有安全区域\
     默认deny any，但是默认deny都是单播报文\
     广播、组播可接收\
     三层设备中如果收到一个广播报文、组播报文会检查自身是否运行对应上层协议，如果运行则转交上层进行处理，如果没有运行则丢弃\
     安全区域中\
**2、接口必须指定为安全区域**\
     防火墙的所有接口必须要有安全区域才可以使用

```apache
    firewall zone ?
                    dmz      Specify dmz security zone
                    local    Specify local security zone
                    name     Indicate a security zone name to be created or deleted
                    trust    Specify trust security zone
                    untrust  Specify untrust security zone
```

**3、必须配置安全策略**\
     防火墙的任意通信，不管是防火墙自己出去，\
     还是经过防火墙出去\
     防火墙独立自主完成数据始发、转发\
     都需要配置安全策略!!!!!

```apache
    security-policy
       rule name T-L
       source-zone local
       destination-zone trust
       action permit
```

4、防火墙——会话表——默认第一次做通信或者使用的时候，会进行首包检测\
      首包检测：从一个接口收到一个数据包后，分析该接口的安全区域，以及经过路由表查询发现目的IP的下一跳的接口的安全区域，是否在我的安全策略中有做放行\
            不放行：该策略直接拦截，不产生任何会话\
            放行：会产生一个临时会话(8s)\
                       会话表会记录当前的SIP、DIP，以及协议号并且产生一个临时的端口号\
      后续如果有数据包到达，会优先查看会话表\
             如果会话表有：则按照会话表进行转发\
             如果会话表没有：则按照安全策略的行为转发\
**5、总结：**\
      路由器的过滤（ACL）是多次查表多次转发，性能消耗大——数据通信使用，流量并没有太夸张\
      防火墙的过滤(安全策略+会话表)一次查表多次转发，性能消耗少——大量的数据清洗和分析

## 三、配置案例1——AR1（trust）访问AR3（untrust）

<img src="/resources/0a7129ac0829433ca3b1b3846d526045.png" alt="4dd14390379dbff132711b0e59d60d22.png" width="510" height="324" class="jop-noMdConv">

1、指定接口Ge 1/0/0 为trust区域，开启local至的ping功能

```apache
firewall zone trust
  add interface GigabitEthernet1/0/0

interface GigabitEthernet1/0/0
  ip address 10.1.12.2 255.255.255.0
  service-manage ping permit
```

2、配置trust区域至local区域的安全策略

```apache
security-policy
  rule name T-L
    source-zone local
    destination-zone trust
    action permit
```

3、指定接口Ge 1/0/1 为untrust区域，配置trust区域至untrust区域的安全策略（在两个路由器上要配置默认静态路由）

```apache
firewall zone untrust
  add interface GigabitEthernet1/0/1

interface GigabitEthernet1/0/1
  ip address 10.1.23.2 255.255.255.0
  
security-policy
  rule name T-U
    source-zone trust
    destination-zone untrust
    action permit
```

4、在安全策略中额外增加源、目的IP的限制

```apache
  rule name T-U
    source-zone trust
    destination-zone untrust
    source-address 1.1.1.1 mask 255.255.255.255
    destination-address 3.3.3.3 mask 255.255.255.255
    action permit

#在防火墙上需要配置相应静态路由，首先要路由表中可达 
ip route-static 1.1.1.1 255.255.255.255 10.1.12.1
ip route-static 3.3.3.3 255.255.255.255 10.1.23.3

```

## 四、虚拟防火墙配置

1、防火墙虚拟系统\
      防火墙虚拟系统是指将一台物理防火墙设备从逻辑上划分为多个虚拟系统\
      虚拟系统之间相互独立，有自己的接口、地址集、用户/用户组、路由表项以及策略，并可通过虚拟系统的管理员进行配置和管理\
2、防火墙上存在根系统和虚拟系统两种类型的虚拟系统。\
      i ) 根系统（Public）\
          根系统是防火墙上缺省存在的一个特殊的虚拟系统。即使虚拟系统功能未启用，根系统也依然存在\
              此时，管理员对防火墙进行配置等同于对根系统进行配置\
              启用虚拟系统功能后，根系统会继承先前防火墙上的配置\
          在虚拟系统这个特性中，根系统的作用是管理其他虚拟系统，并为虚拟系统间的通信提供服务。\
      ii ) 虚拟系统（VSYS）\
           虚拟系统是在防火墙上划分出来的、独立运行的逻辑设备\
3、虚拟系统之间互访\
      虚拟系统之间通过虚拟接口实现互访\
      虚拟接口名的格式为“Virtual-if+接口号”，根系统的虚拟接口名为Virtual-if0，其他虚拟系统的Virtual-if接口号从1开始\ <img src="/resources/87b8df5b80ad46f59c11336dd335f99d.png" alt="d10d8fefa671079231ad23bd069dc377.png" width="681" height="259" class="jop-noMdConv">

1、基础配置\

     LSW5与AR4创建相关vlan以及ospf进程\

2、防火墙虚拟化配置\
     vsys enable //开启虚拟化功能\
     vsys name Employee //创建一个虚拟防火墙，其中Employee为考试所指定的名称\
     assign vlan xxx //添加对应接口到达虚拟防火墙中，后续可以在虚拟防火墙中直接配置

```apache
    vsys enable
    vsys name Employee 
      assign vlan 204
```

    switch vsys Employee //进入创建的虚拟系统，进行配置\

```apache
            destination-zone untrust

            source-zone untrust
            destination-zone trust
```

      **virtual-if 接口判定为untrust区域，配置相关安全策略**\
      全局墙

```apache
    #配置接口
    interface GigabitEthernet1/0/2
        ip address 20.26.9.15 255.255.255.0
    #添加安全区域
    firewall zone trust
       add interface GigabitEthernet1/0/2
    firewall zone untrust
       add interface Virtual-if0
    #配置安全策略
    security-policy
       rule name T-U
          source-zone trust
          destination-zone untrust
          source-address 20.26.9.16 mask 255.255.255.255
          destination-address range 10.1.11.1 10.1.15.254
          action permit
```

      Employee墙

```apache
    #添加安全区域
    firewall zone untrust
       add interface Virtual-if1

       rule name UU-TT
          source-zone untrust
          destination-zone trust

          destination-address range 10.1.11.1 10.1.15.254

```
