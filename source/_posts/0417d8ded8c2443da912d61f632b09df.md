## VxLAN的概念

### VXLAN简介

VXLAN在本质上是一种VPN技术，能够在任意路由可达的物理网络（Underlay网络）上叠加二层虚拟网络（Overlay网络），通过VXLAN网关之间的VXLAN隧道实现VXLAN网络内部的互通，同时，也可以实现与传统的非VXLAN网络的互通

### VXLAN中的重要知识

1、vni vlan bd是干嘛的?\
答：vlan起到内网隔离，vni是在三层的vxlan中的vlan，BD虚拟MAC地址表，和VNI一对一绑定\
2、 他们之间绑定关系是什么？\
答：vlan会根据当前接口接收，当前接口绑定BD域，BD域绑定VNI\
3、int vbdif 到底是和BD数字相关还是VNI数字相关\
答：vbdif主要和本地的BD数字域相关，和VNI数字没关系，但是BD和VNI相关 但是vbdif服务于bd域服务于vni\
4、BD和VNI必须相同数字吗?\
答：不用，只要记得住关系就行，比如 Bridge domain 50 vxlan vni 200\
只是建议写成一样，方便运维

## VxLAN实际配置

<img src="/resources/d402feb5dc4e458389e2fddca728f3ae.png" alt="689765499b01bc8130384098ea091291.png" width="555" height="487">

1、创建一个bridge-domain，并指定一个新的三层vlan-id—VNI

```apache
bridge-domain 10
   vxlan vni 10

```

 

2、与二层交换机的互联接口上设置子接口，指定二层vlan-id，并绑定至对应的bridge-domain\
      该数据包会根据绑定的bridge-domain，打上对应的vni-id

```apache
interface GE1/0/0.10 mode 12
   encapsulation dot1q vid 10
   bridge-domain 10 
```

3、新建一个隧道，指定带vni的数据包如何转发

```
interface Nve1
   source 2.2.2.2
   vni 10 head-end  peer-list 3.3.3.3

```

4、跨vni通信，需要配置vbdif<span style="color: rgb(224, 62, 45);">\*\*（vbdif取决bd域的编号，不是vni的编号）\
\*\*</span>     默认为集中式网关，只需要在一个设备上配置

```
interface Vbdif10
   ip address 192.168.10.254 255.255.255.0
interface vbdif20
   ip address 192.168.20.254 255.255.255.0
```
