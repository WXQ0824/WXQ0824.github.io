### 1、访问外网——防火墙的对应虚拟系统中配置安全策略

Employe虚拟系统中放行采购部（11-15）、市场部（21-25）、内部无线用户（51-55）

```apache
rule name to_Internet           //市场部，采购部、内部无线用户上网
   source-zone trust
   destination-zone untrust
   source-address range 10.1.11.0 10.1.15.255
   source-address range 10.1.21.0 10.1.25.255
   source-address range 10.1.51.0 10.1.55.255
   action permit
```

Guest虚拟系统中放行外部无线用户（101-105）

```apache
security-policy        //Guest用户上网
   rule name to_Internet
   source-zone trust
   destination-zone untrust
   source-address range 10.1.101.0 10.1.105.255
   action permit

```

### 2、内部无线用户访问服务器

Employee防火墙中配置安全策略（内网无线用户访问指定服务器，并拒绝其访问其它服务器）

```apache
security-policy
    rule name Employee_to_Server100    //内网无线用户访问服务器100
      source-zone trust
      destination-zone trust
      source-address range 10.1.51.0 10.1.55.255
      destination-address 10.1.60.100 mask 255.255.255.255
      action permit
    rule name Employee_to_Server //拒绝内部无线用户访问到服务器区的其他资源
      source-zone trust
      destination-zone trust
      source-address range 10.1.51.0 10.1.55.255
      destination-address 10.1.60.0 mask 255.255.255.0
      action deny
```

在X\_T1\_Core1对内部无线用户访问服务器的路由进行重定向，强制路由经过防火墙

```apache
acl number 3000
   rule 5 permit ip source 10.1.51.0 0.0.0.255 destination 10.1.60.0 0.0.0.255
   rule 10 permit ip source 10.1.52.0 0.0.0.255 destination 10.1.60.0 0.0.0.255
   rule 15 permit ip source 10.1.53.0 0.0.0.255 destination 10.1.60.0 0.0.0.255
   rule 20 permit ip source 10.1.54.0 0.0.0.255 destination 10.1.60.0 0.0.0.255
   rule 25 permit ip source 10.1.55.0 0.0.0.255 destination 10.1.60.0 0.0.0.255

interface GigabitEthernet0/0/3
   traffic-redirect inbound acl 3000 vpn-instance Employee ip-nexthop 10.1.200.22

```

在X\_T1\_Core1对服务器对内部无线用户的回包路由进行重定向，同样强制路由经过防火墙

```apache
acl number 3001
   rule 5 permit ip source 10.1.60.100 0 destination 10.1.51.0 0.0.0.255
   rule 10 permit ip source 10.1.60.100 0 destination 10.1.52.0 0.0.0.255
   rule 15 permit ip source 10.1.60.100 0 destination 10.1.53.0 0.0.0.255
   rule 20 permit ip source 10.1.60.100 0 destination 10.1.54.0 0.0.0.255
   rule 25 permit ip source 10.1.60.100 0 destination 10.1.55.0 0.0.0.255

interface GigabitEthernet0/0/6
   traffic-redirect inbound acl 3001 vpn-instance Employee ip-nexthop 10.1.200.22

```

### 3、外部无线用户访问服务器

默认访问路径：207(Guest--trust)——FW——205(全局--untrust)——Core——204(全局--untrust)——FW——206(Employee--trust)——Core——服务器\ <span style="color: rgb(186, 55, 42);">Guest防火墙**无需**增加安全策略（与访问外网的策略一致）</span>\
在Employee防火墙增加安全策略（untrust——trust）

```apache
#使用自定义服务（service-set）
ip service-set Guest_Service type object
    service protocol tcp destination-port 3389份
security-policy
    rule name Guest_to_Server99   //允许外部无线用户访问Server99
    source-zone untrust
    destination-zone trust
    source-address range 10.1.101.0 10.1.105.255
    destination-address 10.1.60.99 mask 255.255.255.255
    service Guest_Service
    action permit
security-policy
    rule name Guest_to_Server     //拒绝外部无线用户访问其他的服务器资源
       source-zone untrust
       destination-zone trust
       source-address range 10.1.101.0 10.1.105.255
       destination-address 10.1.60.0 mask 255.255.255.0
       action deny
```

配置静态路由，将访问路径改为在两个虚拟系统中透传：\
207(Guest--trust)——Guest\_FW——Virtualif\_2(untrust)——Virtualif\_1(untrust)——Employee\_FW——206(Employee--trust)——Core——服务器

```apache
#新增Employee回Guest的回程路由
ip route-static vpn-instance Employee 10.1.101.0 24 vpn-instance Guest 
ip route-static vpn-instance Employee 10.1.102.0 24 vpn-instance Guest 
ip route-static vpn-instance Employee 10.1.103.0 24 vpn-instance Guest 
ip route-static vpn-instance Employee 10.1.104.0 24 vpn-instance Guest 
ip route-static vpn-instance Employee 10.1.105.0 24 vpn-instance Guest 
#新增Guest至Employee的去程路由
ip route-static vpn-instance Guest 10.1.60.99 32 vpn-instance Employee  //Guest to Employee的流量使用Virtual IF接口进行通信
```

Employee防火墙中新增Virtual-if并加入untrust区域

```apache
# 配置virtual-if 1 接口的ip，并加入untrust安全区域
interface virtual-if 1
   ip address 10.1.200.253 32 
firewall zone untrust
  add interface virtual-if 1 
```

Guest防火墙中新增Virtual-if及静态路由

```apache
# 配置virtual-if 2 接口的ip，并加入untrust安全区域
interface virtual-if 2
   ip address 10.1.200.253 32 
firewall zone untrust
  add interface virtual-if 2 
```

### 4、需求5中提供web服务的服务器（10.1.60.101）同样需要在Employee墙中配置安全策略

```apache
rule name Internet_to_Server101    //服务器提供外部访问 
   source-zone untrust
   destination-zone trust
   destination-address 10.1.60.101 mask 255.255.255.255
   service protocol tcp destination-port 80
   action permit 
```
